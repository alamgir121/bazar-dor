project name : বাজার দর

short description : BazarDor  is a responsive web application that helps people in Bangladesh check the prices of everyday market items such as rice, vegetables, fish, meat, and groceries, all in one place. Instead of guessing or relying on word of mouth, users can browse, search, and compare prices quickly and plan their shopping with confidence.

Technology Used:
1. Next.js
2. TypeScript
3. Tailwind CSS
4. daisyUI
5. Better Auth
6. MongoDB
7. react-hot-toast
8. Hind Siliguri font



5 key features of the project
1. Daily Market Prices
2. Search and Filter
3. Sort and Compare
4. Price Trend Tracking
5. Fully Responsive



Getting Started

2.npm install
